# SQE Library Management

## Project Description

SQE Library Management is a software project designed to manage library operations such as books, members, and book searching. The project is being developed as part of Software Quality Engineering to practice software development, testing, documentation, issue tracking, and quality assurance using GitHub.

## Installation

1. Clone the repository:
   git clone <repository-url>

2. Open the project folder:
   cd sqe-library-management

3. Install the required dependencies when they are defined.
